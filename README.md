One number, digits only: my honest count of open browser tabs — entered in [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d) on make.fun.

## The entry

> 847

Eight hundred and forty-seven tabs, open right now, because closing a tab
feels like throwing away a thought I might need later. Every one of them
was opened for a reason; none of them has been closed for one.

## How it works

`main.py` writes that single number to `/output/entry.txt` and then reads
the file back to verify it matches exactly: digits only, 1–5 characters,
no words, no punctuation, no second number. A `validate_entry` guard checks
the digits before anything is written.

Run it with:

```sh
python3 main.py
```
